## 🎨 UI/UX Summary By Phase

### Phase 1: Citizen App
- **Color scheme:** Bright blues + greens (trust + health)
- **Interaction:** Bottom nav (5 tabs) + card UI
- **Users:** Patients (non-technical)
- **Goals:** Find care, check meds, learn health info

### Phase 2: Authority Dashboard
- **Color scheme:** Dark theme + accent colors (command center)
- **Interaction:** Tabs (Live | Forecast | Alerts | Rec.)
- **Users:** District admins (technical)
- **Goals:** Oversight + approvals

### Phase 3: Emergency Mode
- **Color scheme:** Blood-red pulsing (critical alerts)
- **Interaction:** Toggle buttons + real-time updates
- **Users:** State director (during crisis)
- **Goals:** Mobilize resources fast

### Phase 4A: Mobile App
- **Color scheme:** Same as Phase 1 (consistency)
- **Interaction:** 5-language support, gesture-friendly
- **Users:** PHC staff (field workers)
- **Goals:** Access approvals, workflow status, export data

### Phase 4C: Dashboard Customization
- **Color scheme:** Light + dark mode toggle
- **Interaction:** Drag-drop widgets, grid checkboxes
- **Users:** IT admins (customization)
- **Goals:** Configure per-role layout, export scheduling

### Phase 5: Intelligence Layer
- **Color scheme:** Dark (navy/deep blue) + accent neons
- **Interaction:** Sliders (what-if), drill-down hierarchy, animations
- **Users:** Advanced operations teams
- **Goals:** Deep insights, scenario testing, learning visualization

### Mission Control (Judges' Demo)
- **Color scheme:** Dark (command center) + gradient text
- **Interaction:** Button clicks, time toggle, real-time animation
- **Users:** Judges, investors, executives
- **Goals:** Understand system in 10 minutes → approve funding
